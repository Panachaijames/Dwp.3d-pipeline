DD Material Code Tagger

A new render annotation tool for the DD (Design Development) phase. Users can upload a render, click to place draggable material code labels directly on the image, and export an annotated PNG with all codes overlaid.

  • Click-to-place annotations with drag-to-reposition support
  • Zoom control and adjustable label scale
  • Detailed colour mode for label visibility on light/dark renders
  • Canvas-based export that bakes annotations into the final image
  • Added as a new render mode: "Material Code Tagger" in the Workspace

DD Phase Material Schedule

A full project-level material code library is now embedded in the app, covering all DD phase finish categories with human-readable descriptions.

  • Categories: Metal, Tile, Stone, Paint, Laminate, Leather, Fabric, Wallpaper, Glass & Mirror
  • Used by the Material Code Tagger for auto-complete when placing annotations

NEW

Google Sheets Material Export API

A new backend endpoint aggregates all placed material annotations, appends AI-generated price estimates, and pushes the result directly to a Google Sheet via the Sheets API.

  • Deduplicates annotations by code and counts quantities per room
  • Attaches source links and price range estimates
  • Uploads an annotated reference image to Google Drive alongside the sheet
  • Max execution time: 60 seconds
app/api/sheets/export/route.ts
NEW

3D Model Backup Tab (Google Drive)

The Models tab now includes a dedicated Backup tab that lets users upload 3D resource files directly from the browser to a chosen Google Drive folder — bypassing the server to handle large files efficiently.

  • Supported types: .jpg, .jpeg, .png, .bmp, .tif, .tiff, .tga, .vrmesh, .ies, .hdr, .tx, .exr
  • Inline Drive folder picker with breadcrumb navigation
  • Create new subfolders directly from the picker
  • Per-file upload progress with error reporting
  • Direct browser → Drive upload (no server buffer)

Material Board Image Generation (Imagen)

The PromptGenWorkspace now supports AI-driven material board image generation using Imagen. A reference image can be analysed by Gemini (furniture & plant detection) before passing the description to Imagen to generate flat-lay material board variations.

  • Added singleImage mode to Imagen API — runs a single prompt as-is instead of splitting into multiple sections
  • Added imageData pass-through for image-to-image input
  • Structured reference analysis prompt extracts chair type, upholstery, plant, and colour story
